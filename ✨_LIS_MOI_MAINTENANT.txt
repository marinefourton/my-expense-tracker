  ✅ Entièrement gratuit

  1. Crée un App Password Wanadoo (2 min)
     → https://www.wanadoo.fr → Paramètres → Sécurité

  2. Active les alertes dans Caisse d'Épargne (2 min)
     → App Caisse d'Épargne → Paramètres → Alertes

  3. Lance l'app (1 min)
     → npm install && npm start
     → http://localhost:5000
